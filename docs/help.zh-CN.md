# efto 使用帮助

efto 是一个 Windows 桌面启动器（macOS 支持进行中：CLI 与搜索/启动/插件链路已可用，GUI 见 `docs/macos-support-plan.md`）：`Alt+Space` 唤起，输入即搜，回车启动应用或执行动作。版本 0.1.0。

## 1. 快速开始

1. 按 `Alt+Space` 唤起搜索框（可在 设置 → 启动器 中改热键）。
2. 直接输入应用名、拼音、首字母、URL、文件路径或内置指令。
3. `Enter` 执行当前选中项，`Esc` 清空输入；输入为空时再按 `Esc` 隐藏窗口。
4. 鼠标规则：可复制的行（计算器、时间戳、命令输出）**单击即复制**；应用、插件、文件等**双击执行**。
5. 结果很多时用 `↑` `↓` 或 `Ctrl+P` `Ctrl+N` 移动，鼠标滚轮也可以。

| 按键 | 作用 |
| --- | --- |
| `Alt+Space` | 唤起 / 聚焦搜索框 |
| `Enter` | 执行选中项；无结果时把输入当路径或 URL 打开 |
| `Esc` | 清空输入；输入为空时隐藏窗口；命令执行中取消命令 |
| `↑` `↓` / `Ctrl+P` `Ctrl+N` | 移动选中项 |
| `←` `→` | 默认面板中横向移动 |
| `Shift` | 按住预览当前选中项，再按一次关闭 |
| `Alt+1..9` | 执行搜索结果中的第 N 行；默认面板中执行第 N 个常用工具 |
| `Tab` | 文件结果上打开文件动作菜单（打开方式、复制路径、删除等） |
| `Ctrl+Enter` | 文件结果上加入文件缓冲 |
| `Alt+R` | 重建应用索引 |
| `Alt+P` | 打开设置 |

通用动作热键默认是 `Ctrl+Alt+Space`（设置 → 启动器 可开关与修改；macOS 暂不支持本功能）：在任意应用里选中文本后按下，
可直接复制、粘贴回前台窗口、用浏览器搜索，或打开选中的链接/路径。在 设置 → 模型 配好模型且安装了
翻译（`translate`）/ AI 对话（`ai-chat`）插件时，菜单还会多出"翻译选中文本"与"用 AI 追问"：
翻译结果内联显示在主窗口，AI 会打开插件窗口并带入选中的文字。

## 2. 应用搜索与启动

- 索引来源包括开始菜单、桌面快捷方式、注册表 App Paths 与常见安装目录；`.lnk` 会解析出真实目标。
- 支持中文拼音全拼、首字母和子序列匹配，例如 `wx`、`weixin` 都能找到微信。
- 使用频次会影响排序：常启动的应用会自然靠前。
- 设置 → 索引 可以：
  - 选择“索引条目”显示哪些来源；
  - 开关“启用注册表索引”“扫描安装目录”；
  - 添加“自定义索引目录”；
  - 设置自动刷新间隔；间隔为 0 时只能手动按 `Alt+R` 重建。
- 自带忽略规则会跳过卸载程序、帮助文档等噪声条目；自定义目录同样按此规则过滤。

## 3. 直接打开

以下输入不需要索引，回车会直接打开：

- 完整 URL：`https://example.com`、`http://...`。
- Windows 设置页：`ms-settings:display`、`ms-settings:windowsupdate`。只输入 `ms-settings:`
  会列出常用设置页，继续输入（如 `ms-settings:blue`）可过滤。
- 已存在的文件或文件夹路径：`C:\Windows`、`D:\project\readme.md`。
- 以 `~` 开头的用户目录：`~\Downloads`、`~\.efto`。
- 无搜索结果时按 `Enter`，也会把输入本身当路径或 URL 再试一次。

## 4. 内置搜索源与严格判定

内置搜索源只在输入**明确符合条件**时出现，避免抢走应用搜索：

- **计算器**：整行都是合法算式（如 `12*3+7`、`sqrt(2)`）才出现；含字母的普通输入不会触发。
- **时间戳**：十进制数字且位数符合秒/毫秒时间戳范围；`2026` 这类普通数字不会被误判。
- **系统时间格式**：八种固定格式（如 `2026-11-19`、`2026/11/19 08:30`、`08:30:00`）只在整行匹配时出现，并在结果行里显示对应的日期时间。
- **文件检索**：Windows 用 Everything（`es.exe`），macOS 用系统自带的 Spotlight（`mdfind`）。文件结果只补在应用结果之后，分数低于所有应用条目；不会挤掉应用。
  - macOS 默认检索「桌面 / 文档 / 下载」，并跳过 `node_modules`、`.git`、系统缓存等噪音；其它文件夹可在 设置 → 通用 → 文件检索（Spotlight）里点「添加目录」纳入范围。
- **浏览器收藏夹**：查找 Chrome / Edge 书签，只有打开“检索收藏夹”后参与搜索，同样排在应用之后。
- **片段**：输入与某个片段关键词**完全一致**时出现；前缀或多余字符不会触发，避免劫持普通搜索。
- **网页搜索**：输入 `<关键词> <正文>`，例如 `g rust 生命周期`、`wiki 爱因斯坦`。关键词必须单独成段且后面有正文；命中后不再显示本地结果。
  - 只输入关键词本身时会先给出一条用法提示（「用 Bing 搜索…」），提示不会挤掉本地应用结果，按 `Enter` 也只回一句用法说明。
  - 默认关键词：`b` 百度、`g` Bing、`gh` GitHub、`wiki` 维基百科；可在 设置 → 网页搜索 增删改，URL 用 `{q}` 占位。
  - 本地完全没有结果时，若开启“无结果时兜底搜索”，会追加一条默认引擎的搜索入口；它永远排在真实结果之后。
- **系统命令**：整串等于以下关键词时出现，`Enter` 执行：`sleep`/`睡眠`、`restart`/`重启`、`logout`/`注销`、`emptytrash`/`清空回收站`、`screensaver`/`屏保`。
  - 重启、注销、清空回收站会先弹出系统确认框；取消不执行。`sleep now`、`重启电脑` 这类带附加文字的输入不会触发。

## 5. Shift 预览

- 按住 `Shift` 预览当前选中项；松手不关闭，再按一次 `Shift` 关闭。
- 支持文本、图片、视频、网页、PDF、本地 HTML 与文件属性面板。
- 网页预览带“打开 / 关闭”浮层；`Shift` 也能关闭。
- 预览抢焦点时不会触发“失焦自动隐藏”，回到搜索框后继续操作即可。

## 6. 常用工具

> macOS 当前提供：搜索/启动应用、计算器与时间、命令源、插件、剪贴板历史、片段、锁屏、
> 操作窗口（平铺/半屏/最小化/还原）、快捷键指南、通用动作、文件缓冲、系统命令（睡眠/
> 重启/注销/清空废纸篓/屏保）、文件检索（Spotlight）、系统设置搜索、hosts 编辑插件、
> 窗口列表/聚焦。平铺、键盘模拟与截图需要在 设置 → 权限 中授予辅助功能 / 屏幕录制。

默认面板（输入为空时）包含“最近使用”和“常用工具”两组：

- **截图**：框选截图，选区出现后可在选区内按住拖动整体移动位置（标注随选区一起移动），再按需重拖空白处重新框选；可用工具栏标注：矩形/椭圆/箭头/画笔/荧光笔/马赛克/文字/橡皮（数字键 `1-8` 切换），8 色色板与三档粗细，`Ctrl+Z`/`Ctrl+Y` 撤销重做；标注会随截图一起复制/保存/钉在屏幕。也支持滚动长图（有标注时不可用）。
- **剪贴板**：记录文本、图片与文件列表；单击复制，`Ctrl+Enter` 复制并粘贴回前台窗口，`P` 置顶，`Delete` 删除。
- **锁屏**：立即锁定 Windows。
- **操作窗口**：选中后先展开二级菜单——网格平铺（平铺窗口）、最小化其他窗口（保留搜索框下方那个）、最小化全部窗口、左/右半屏、还原上次平铺。网格平铺只处理搜索框所在显示器；最小化作用于所有显示器；最小化窗口跳过，efto 自身窗口、桌面与任务栏不参与。单项热键仍直接网格平铺，不弹菜单。
- **快捷键指南**：记住唤起搜索框前的应用，打开独立窗口列出它的快捷键；可下拉切换应用、输入筛选，`Esc` 关闭。内置覆盖 Windows、Office、浏览器、VS Code、Photoshop、Figma、IDEA 与 Trae；未收录的应用回退到 Windows 通用快捷键。
  - 用户可用 `~/.efto/shortcuts/<exe>.json` 覆盖或补充内置数据：同名分组按 `keys` 合并（用户优先），新分组直接追加；单个文件损坏只影响它自己。
  - CLI 可以按同一格式导入：`efto.exe cli import-shortcuts --file <路径> --json`（省略 `--file` 时从 stdin 读，`--dry-run` 只报告不写盘）。
- **片段**：在 设置 → 片段 维护关键词与正文，正文支持 `{date}`/`{time}`/`{datetime}`。搜索框输入完整关键词后回车，展开结果会复制并粘贴回唤起前的窗口；不做系统级逐字自动替换。
- **文件缓冲**：对多个文件执行批量操作。文件结果上按 `Ctrl+Enter` 或从动作菜单选“加入文件缓冲”，再从默认面板打开“文件缓冲”窗口，可复制到剪贴板、复制到…、移动到…、删除到回收站或清空。
- **颜色提取器**：唤起时冻结当前屏幕，移动光标在放大镜里查看光标处像素的 HEX/RGB，单击或 `Enter` 把 HEX 复制到剪贴板，`Esc` 取消。动画/视频里的颜色以冻结帧为准。默认**不**加入常用工具，可在 设置 → 常用工具 勾选。
- **便签纸**：每次新建一张置顶便签，输入文本自动保存；标题栏可拖动，右上角 `×` 关闭并删除该条。多条便签可同时钉在屏幕上，重启后按上次位置恢复。默认**不**加入常用工具，可在 设置 → 常用工具 勾选。
- **文件动作**：文件结果上按 `Tab`（或点行尾 `⋯`）打开动作菜单，支持打开、打开方式、在资源管理器中定位、复制路径、复制文件、加入缓冲、复制到…、移动到…、删除到回收站。
- 自定义应用/插件也可以加入常用工具；在默认面板中用 `Alt+1..9` 直接执行，或 `←` `→` 选中后回车。
- 调整顺序：**直接在默认面板里拖动工具卡片**即可重排（松手自动保存）；也可以在 设置 → 通用 → 常用工具 →「面板顺序」里拖动。顺序决定面板展示与 `Alt+1..9` 的对应关系。
- **单项热键**：在 设置 → 单项热键 给截图、剪贴板、锁屏、操作窗口、快捷键指南、片段、文件缓冲分别绑定全局热键，按一下直接执行，不用先唤起搜索框。默认 `Ctrl+Alt+1…7` 依次对应这七个工具；颜色提取器与便签纸默认不占用热键，需要时可在同一页手动绑定。点击输入框后直接按下组合键即可录入，留空表示不绑定；与唤起热键或通用动作热键重复的组合会被丢弃。
- 最近使用可以一键清空。

## 7. 插件

- 插件通过 `efto-plugin.json` 描述，放入插件目录后自动加载；设置 → 插件 可以导入与查看。
- 触发词命中后回车唤起插件；支持为命令设置别名。
- 插件可以注册动态搜索项、打开自己的 UI、调用 `efto.*` 能力（通知、剪贴板、文件、HTTP、AI 等）。
- TS 插件只做类型剥离，不生成运行时代码：不支持 `enum`、带值 `namespace`、装饰器与 JSX。
- 没有 Node/npm 依赖：插件在嵌入的 V8 中运行，不能 `require` CommonJS 包。
- **Markdown**：输入 `md` / `markdown` 打开插件，支持文档 / 源码双模式。用「打开文件」或把文件拖进窗口后可直接编辑并保存回原文件，也可导出为独立 HTML 或打印；新建文档保存时走系统保存框。

## 8. 设置项

设置页左侧分为七页：

- **常规**
  - 外观：主题（跟随系统 / 深色 / 浅色）。
  - 启动器：全局热键、通用动作热键与开关、最大结果数、失焦自动隐藏、窗口置顶。
  - 常用工具：截图、剪贴板、锁屏、操作窗口、快捷键指南、片段、文件缓冲、颜色提取器、便签纸的开关；
    下方「面板顺序」列表可以**用鼠标拖动左侧手柄**调整顺序（顺序即默认面板的展示顺序与 `Alt+1..9` 编号），
    自定义应用/插件条目也能拖动或移除。
  - 索引：条目来源、自动刷新、注册表索引、安装目录扫描、自定义目录。
  - 浏览器收藏夹：是否参与检索。
  - Everything：本体与 `es.exe` 状态，可一键安装 `es.exe`。
  - 命令执行：见第 13 节。
  - 界面语言：跟随系统 / 简体中文 / English。
- **片段**：维护关键词、展示名与正文；关键词不能含空格且不能重复。
- **网页搜索**：管理搜索引擎（关键词、名称、含 `{q}` 的 URL）、无结果兜底开关与兜底引擎。
- **单项热键**：给 7 个内置工具绑定独立全局热键。
- **插件**：导入插件、查看已安装插件、逐项停用 / 启用（停用后不参与搜索与唤起，插件文件保留）、打开插件目录。
- **运行时**：Node.js 与 Python 解释器路径，可检测是否可用；留空时启动会自动从系统 PATH 探测并填入，之后仍可修改。未配置或检测不通过时，卡片里会显示安装引导与官网下载入口（Node.js LTS；Python 安装时需勾选「Add python.exe to PATH」）。
- **模型**：OpenAI 兼容接口的模型列表与默认模型，供插件 `efto.ai.chat` 调用。

保存后立即生效；热键或主题变化会同步应用到所有窗口。

## 9. 托盘菜单

右键（或左键）托盘图标：

- **显示搜索框**：等同于热键。
- **设置…**：打开设置窗口。
- **帮助文档**：打开本窗口。
- **退出 efto**：停止插件运行时并退出。

## 10. CLI 通道

无需 GUI 即可脚本化调用，适合 agent 与自动化：

```powershell
efto.exe cli index --json
efto.exe cli search "chrome" --limit 5 --json
efto.exe cli launch --id <hit-id>
efto.exe cli plugins --json
efto.exe cli plugin-run <plugin-id> --wait-ms 3000 --json
efto.exe cli run-command "git status" --json
efto.exe cli import-shortcuts --file shortcuts.json --json
efto.exe cli capabilities --json
```

- 退出码：`0` 成功、`1` 执行失败、`2` 参数错误、`3` 未找到。
- 大部分子命令支持 `--json`，输出机器可读结果。
- `--dry-run` 只打印将要执行的动作（`launch`、`files`、`action`、`focus`、`run-command`、`import-shortcuts`）。
- `import-shortcuts` 的 JSON 与 `~/.efto/shortcuts/<exe>.json` 同构：
  `{"app":{"exe":["trae cn.exe"],"name":"Trae"},"groups":[{"name":"文本编辑","items":[{"keys":"Ctrl+Enter","action":"新建一行进行编辑"}]}]}`。
  按同名分组 + `keys` 合并、导入数据优先，重复导入幂等；`capabilities --json` 里有完整格式示例。
- 用 `capabilities --json` 查看当前版本支持的全部子命令与参数。

## 11. 数据与配置

- 数据根目录：`%USERPROFILE%\.efto`
  - `settings.json`：全部设置。
  - `snippets.json`：片段；`shortcuts/`：快捷键指南的用户覆盖数据。
  - `clipboard.json` 与 `clipboard-images/`：剪贴板历史与图片文件。
  - 索引缓存与使用记录：删除后下次启动会重建。
  - 插件数据、钉图等。
- `EFTO_PLUGIN_DIRS`：追加插件目录（多个用 `;` 分隔）。
- `EFTO_LOCALE`：覆盖语言环境标识。
- `RUST_LOG`：调整日志级别，例如 `RUST_LOG=debug`；日志写 stderr，不会污染 `--json`。

## 12. 已知限制与故障排查

- **没有 Node 运行时**：插件只能使用 efto 提供的能力；CommonJS 包不可用。
- **TS 仅类型剥离**：不使用 tsc 生成代码，`enum`、带值 `namespace`、装饰器、JSX 会直接报错。
- **文件检索**：Windows 依赖 Everything，未安装或 `es.exe` 不可用时文件源不出结果（设置里可一键安装）；macOS 用系统自带的 Spotlight，无需安装；默认只检索桌面 / 文档 / 下载，可在设置里追加目录。
- **UWP 应用可能未索引**：部分商店应用没有传统快捷方式；可尝试从开始菜单重新创建快捷方式。
- **热键冲突**：被其它程序占用时启动会记录错误；换一个组合后保存即可。
- **索引为空**：连续三次自动重建得到 0 条会停止自动重建，请检查索引来源后按 `Alt+R` 手动重建。

## 13. 命令执行

在搜索框输入命令前缀（默认 `>`）即可直接执行命令：

```text
> ipconfig /all
> git status
> python -V
```

- 入口判定：**只有行首前缀**才进入命令源；一旦命中，应用/计算器/文件等结果全部让路。前缀默认为 `>`，可在设置里修改，但不能使用字母、数字或空白。
- 输出呈现：
  - **内联输出**（默认）：命令在后台执行，stdout / stderr 逐行回到下拉列表；单击任意一行即可复制，stderr 显示为红色。
  - **终端窗口**：打开独立终端执行，适合需要交互输入的程序（macOS 暂不支持终端模式，会明确报错；v1.5 接 Terminal.app）。
- 执行中按 `Esc` 会立即杀掉子进程。
- 超时默认 10 秒（可设 1–60 秒），超时同样会杀掉子进程。
- Shell 按平台取值：Windows 可选 PowerShell、PowerShell 7+、cmd、Git Bash、WSL 与自定义；
  macOS 可选 zsh、bash、fish 与自定义（默认 zsh）。跨平台复用的配置文件会在加载时回落到平台默认 Shell。
  - WSL 可填写发行版名，留空使用默认发行版。
  - 自定义 Shell 必须填写可执行文件路径，并可写参数模板（`{cmd}` 会被替换成实际命令）。
  - 设置页的“检测”按钮会真跑一条 `echo`，确认 Shell 能启动。
- 安全提示：命令以当前账户权限执行，管道、重定向、环境变量都取决于所选 Shell；请不要在共享脚本里回显敏感信息。

命令行等价入口：

```powershell
efto.exe cli run-command "ipconfig" --json
efto.exe cli run-command "ipconfig" --dry-run
```
