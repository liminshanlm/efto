# quickweb — efto 插件（网页快开）

输入触发词直接打开常用网站、AI 站点与资讯聚合页；支持带关键词的站内搜索与自定义站点。

## 目录

```
quickweb/
├── efto-plugin.json   # 74 条触发命令
├── main.js            # 触发词 → URL → openExternal
├── lib/sites.js       # 69 条内置站点表
├── index.html         # 管理界面
├── ui/app.js          # 管理界面逻辑（列表、筛选、内置/自定义删除）
├── ui/app.css         # 管理界面样式（与主应用同一套令牌）
├── logo.png / res/    # 图标（管理界面按站点显示）
└── LICENSE.txt        # react 依赖的许可声明
```

## 用法

**直接打开内置站点**（69 条）：

```
DeepSeek
Github
哔哩哔哩
A股
36氪
Smallpdf
```

**带关键词的站点**（网址里有 `{query}`，会做 URL 编码）：

```
百度搜索 efto 启动器
谷歌搜索 rust tauri
GitHub actions 缓存
知网 时序数据异常检测
```

只敲触发词不给关键词时，插件会输出一行提示告诉你补什么，不会开一个空搜索页。

**自定义站点**：

```
添加快开 我的博客 https://example.com
我的博客                     # 之后直接这样打开
添加快开 内网 wiki https://wiki.internal/?q={query}
```

同名再次添加会覆盖网址。协议只接受 `http` / `https`。
添加后站点名会同步进启动器搜索（`efto.setSearchItems`），清空关键词后直接搜站点名回车即可打开。

**管理界面**：输入 `网页快开`（或 `web` / `quickweb`）回车打开。可以按触发词/网址筛选、查看全部内置项、点卡片直接打开；内置项和自定义项都可以删除，自定义项可在底部表单里新增。

## 已知边界

- **只用系统默认浏览器**：不提供自动化浏览器，也不会向页面注入输入。带 `{query}` 的站点在触发词后一次性传入关键词。
- **截图/图片/文件投递不支持**：宿主不向插件提供截图，也不支持把文件拖进目标网页（`cmds[].type="over"` 未实现）。
- **搜索联想不做**：启动器没有二次输入联想挂点，关键词与触发词一起输入。
- **自定义项无分类**：管理界面是平铺列表，不提供分组与拖拽排序。
- **删除内置项只作用于插件内**：清单里的静态触发词仍会被启动器搜索命中，回车会提示已删除；需要完全恢复时，用「添加快开」把同名站点加回自定义列表。
