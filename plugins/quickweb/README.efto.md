# quickweb — efto 插件（网页快开）

输入触发词直接打开常用网站；触发词后加关键词即在站内搜索，不额外记一套命令。
支持自定义站点。

## 目录

```
quickweb/
├── efto-plugin.json   # 57 条触发命令（52 个站点 + 5 条管理命令）
├── main.js            # 触发词 → 主页 / 站内搜索 → openExternal
├── lib/sites.js       # 52 条内置站点表（一个站点一条记录）
├── index.html         # 管理界面
├── ui/app.js          # 管理界面逻辑（分组 tab、筛选、内置/自定义删除）
├── ui/app.css         # 管理界面样式（与主应用同一套令牌）
└── logo.png           # 插件图标（自绘）
```

站点图标不使用任何第三方 Logo：管理界面按触发词首字与名称散列色相自绘占位图标。
内置站点只保存触发词、URL 与分组，站点名称与商标归各自所有者，这里仅用于跳转。

## 用法

**直接打开站点**（不带关键词 → 打开主页）：

```
知乎
雪球
Github
哔哩哔哩
A股
36氪
Smallpdf
```

**站内搜索**（触发词 + 关键词 → 打开该站搜索页）：

```
知乎 efto 启动器
知网 时序数据异常检测
Github actions 缓存
Unsplash 山
```

同一个站点只有一条记录：只敲触发词就打开主页，补上关键词就变为站内搜索。
没有搜索能力的纯跳转站（如「天气」「Smallpdf」）只打开主页。

**自定义站点**：

```
添加快开 我的博客 https://example.com
我的博客                     # 之后直接这样打开
添加快开 内网 wiki https://wiki.internal/?q={query}
内网 wiki 部署文档           # 带 {query} 的会拼搜索地址
```

同名再次添加会覆盖网址。协议只接受 `http` / `https`。
添加后站点名会同步进启动器搜索（`efto.setSearchItems`），清空关键词后直接搜站点名回车即可打开。

**管理界面**：输入 `网页快开`（或 `web` / `quickweb`）回车打开。

- 顶部 tab：全部 / 网页 / 工具 / AI / 聚合；工具类站点单独成组。
- 右上角筛选框跨分组搜索触发词与网址，有筛选时忽略当前 tab。
- 点卡片直接打开主页；带「关键词」标记的站点支持站内搜索。
- 内置项和自定义项都可以删除，自定义项可在底部表单里新增。

## 已知边界

- **只用系统默认浏览器**：不提供自动化浏览器，也不会向页面注入输入。
- **截图/图片/文件投递不支持**：宿主不向插件提供截图，也不支持把文件拖进目标网页（`cmds[].type="over"` 未实现）。
- **搜索联想不做**：启动器没有二次输入联想挂点，关键词与触发词一起输入。
- **自定义项无分类**：管理界面是平铺列表，不提供分组与拖拽排序。
- **删除内置项只作用于插件内**：清单里的静态触发词仍会被启动器搜索命中，回车会提示已删除；
  需要完全恢复时，用「添加快开」把同名站点加回自定义列表。

## 验证记录

- `cli plugins`：清单解析通过，57 条命令全部识别。
- `cli plugin-run`：纯跳转站打开主页；带关键词的站点编码后拼到搜索地址；无关键词时打开主页。
- 桩宿主单测：自定义项新增与覆盖、非法协议拒绝、`custom-save` 的清洗逻辑、隐藏项 code 兼容旧 `xxx@group` 写法。
- 管理界面在无头浏览器下渲染正常，tab 切换、筛选与新增表单工作正常。
