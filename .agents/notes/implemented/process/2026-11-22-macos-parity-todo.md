# Windows 功能改动增加 macOS 同步清单

- **Date**: 2026-11-22
- **Status**: done
- **相关**: `AGENTS.md`、`docs/macos-parity-todo.md`

## 背景

双端并行开发后，Windows 侧新增的功能（命令、快捷键、界面入口、插件 API）
在 macOS 侧是否已具备、要不要适配，此前只散落在聊天记录与提交信息里，
macOS 侧接手时需要重新考古。

## 决定

- `AGENTS.md` 硬性约定新增第 10 条：Windows 侧新增/变更用户可感知功能时，
  同一次改动里往 `docs/macos-parity-todo.md` 追加一行。
- 清单固定六列：功能、Windows 实现位置、macOS 待办（缺失/需适配/已具备）、
  同步要点与验证、状态、备注。
- 状态取值 `待同步` / `适配中` / `已同步` / `不适用`；mac 补齐后标 `已同步` 并写提交。
- 纯内部重构不登记，避免清单被噪音淹没。
- `AGENTS.md` 参考文档列表同步加入该文件，保持"一个事实只有一个家"。

## 验证

纯文档约定，无代码改动；`AGENTS.md` 第 10 条与参考文档两条均已写入。
